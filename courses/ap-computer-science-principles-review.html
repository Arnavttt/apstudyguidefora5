Exam Day Tips

✓

Know the difference between lossless and lossy compression with examples.

✓

Practice reading pseudocode—the AP CSP exam uses a specific pseudocode style.

✓

Expect multiple questions on intellectual property, open-source, and creative commons.

✓

For Create PT, start early: 12 hours sounds like a lot but documentation takes time.
